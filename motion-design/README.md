# OpenGate Motion Design

Use this area for motion work that supports OpenGate's commercial story without mixing editable production files into the deployed website.

## Folders

- `briefs/` — objectives, audience, copy, specifications, and delivery requirements.
- `storyboards/` — shot lists, frames, timing, and transition plans.
- `source/` — editable project files, compositions, audio, and source footage.
- `references/` — approved inspiration and visual references.
- `exports/` — review renders and final deliverables.

Only optimized, approved web deliverables should be copied into the website root. Source files and working exports must remain excluded from Vercel.
