# Private Discuss archive

This folder preserves the removed Private Discuss page and its media for possible future restoration.

It is excluded from Vercel by the root `.vercelignore`, so none of these files are part of the published website.

To restore the section later:

1. Move `private-discuss.html` and the `private-discuss-*` media files back to the project root.
2. Re-add the page to the Technologies dropdown and footer in `site.js`.
3. Re-add `/private-discuss` to `sitemap.xml` and the route helpers in `site.js`.
