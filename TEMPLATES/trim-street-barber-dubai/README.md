# Trim Street Barber Dubai

Static website for a bright, modern barbershop in Downtown Dubai.

## Files

- `index.html`
- Root-level images referenced by the site for simple GitHub/Vercel deployment
- `images/` backup folder with the same assets

## Preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 4182
```

Then visit `http://127.0.0.1:4182/`.

## Notes

- Map section links to Burj Khalifa in Google Maps.
- WhatsApp booking link uses a sample UAE number that can be swapped before launch.
