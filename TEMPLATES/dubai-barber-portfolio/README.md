# Miraj Grooming House

Portfolio mock website for a fictional luxury barber studio in Dubai.

## What is included

- `index.html` single-file static site
- Generated and optimized website assets copied beside `index.html` for simple GitHub/Vercel deployment
- Mobile-first layout for WhatsApp-heavy traffic
- Service menu with AED prices
- Barber profiles
- Gallery lightbox
- Interactive WhatsApp booking drawer
- No build tools, no dependencies, no backend

## Local preview

Open `index.html` directly in a browser.

## Deploy on Vercel

1. Create a new GitHub repository.
2. Push this folder to the repo.
3. In Vercel, create a new project and import the repo.
4. Choose framework preset: `Other`.
5. Leave build command empty.
6. Leave output directory empty.
7. Deploy.

## Customization

- Replace the mock WhatsApp number in `index.html`:
  - Search for `971501234567`
- Update prices in the `#menu` section.
- Replace the root-level image files, such as `hero.jpg` and `gallery-fade.jpg`, with real client assets.
- The old `images/` folder can be ignored; `index.html` uses root-level image paths.
- Update meta tags in the document `<head>` before publishing.

## Note

This is a fictional portfolio concept. The barbershop, profiles, prices, and WhatsApp number are mock data.
